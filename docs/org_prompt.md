Hiện tại, khi dùng chrome vào 1 website như https://chat.zalo.me thì chrome cho phép install ứng dụng (thực ra là tạo 1 trình duyệt không có header) để tạo ra 1 ứng dụng webview.

Tương tự như vậy, tôi muốn tạo 1 ứng dụng như sau:
- Chạy trên linux
- Cho phép tuỳ biến thêm nhiều website. mỗi website là 1 profile riêng.
- Cho phép tuỳ biến: thêm 1 xpath selector, sẽ kiểm tra định kỳ nếu element này tồn tại thì sẽ gửi thông báo đến hệ thống (làm sáng taskbar, thêm indicator ở icon ở taskbar, tạo notification đến hệ thống ....)
- Khi focus vào app thì sẽ tắt các active state đi (sáng taskbar, idicator)
- cho phép tạo shortcut lên start menu của kde hoặc của gnome (nơi chứa ứng dụng)
